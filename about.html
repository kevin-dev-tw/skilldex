how the ledger is kept.

A generated index, not a directory anyone edits by hand.

The method

Three scripts do the whole thing.

fetch

A script walks each source repository's tree on GitHub, reads every SKILL.md frontmatter for its name and description, and merges the community's awesome lists.

build

Duplicates fold away, every entry lands in one of eleven categories, and the page is written from the data file. Nobody edits the list by hand.

verify

Each link is resolved to its repository root and checked, so a row always opens a live project page, not a buried file that may have moved.

Two kinds of source

repository

A GitHub repository whose SKILL.md files were read directly: microsoft, google, anthropics, openai, superpowers and the independent authors. Descriptions are the authors' own words.

list

Awesome-style indexes the community keeps by hand. Their entries are kept as the list wrote them, with the list as the source.

Cadence

Generated 2026-11-12. The ledger is rebuilt when the data is refetched, so the index and its sources never drift apart.

Add a source

New sources join through the fetch list. A good candidate is a repository with SKILL.md files at its root, or a maintained awesome list.
